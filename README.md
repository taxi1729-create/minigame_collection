# あそびばこ — 単発ミニゲーム集

スマホのブラウザですぐ遊べるミニゲーム集です。タイトル画面からゲームを選び、どのゲームも左上の **ホーム** ボタンで進行状況をセーブしてタイトルに戻れます。次に開くと「つづきから」で再開できます。

## 収録ゲーム

| ゲーム | 人数 | 内容 |
|---|---|---|
| あいまいアンサー | 3〜8人 | 伝えすぎたら0点。一部の人だけに当たるヒントを出す |
| 無言トーク | 2人〜 | しゃべらずに3分でエピソードを伝える |
| 異種伝言ゲーム | 2〜7人 | 人ごとに違う表現手段で伝える伝言ゲーム |
| 同母音異義語ゲーム | 1〜6人 | 同じ母音の言葉をヒントから当てる |
| ピタッと10秒 | 1人 | 見えないストップウォッチを10.00秒で止める（5回勝負） |
| いろことば | 1人 | 文字ではなくインクの色を答える30秒チャレンジ |
| すべらせパズル | 1人 | 3×3 / 4×4 のスライドパズル |

## 構成

```
index.html            タイトル（ゲーム選択）
kit/kit.css           共通UI（段ボール＋紙ラベル＋二色ズレ影）
kit/kit.js            共通機能：効果音・セーブ・ホームボタン・クリア演出・トースト・確認ダイアログ
games/<id>/index.html 各ゲーム
```

### 新しいゲームを追加するとき

1. `games/<id>/index.html` を作り、`../../kit/kit.css` と `../../kit/kit.js` を読み込む
2. `<body class="kit">` にして、共通クラス（`k-panel` `k-btn` など）で組む
3. `Kit.mount({ id, title, onSave })` でトップバーを付ける。`onSave` は途中経過のオブジェクトを返す（終わっていれば `null`）
4. 起動時に `Kit.load(id)` で再開、クリア時は `Kit.celebrate()`、失敗時は `Kit.fail()`
5. `index.html` の `GAMES` 配列に1行追加

効果音は Web Audio で合成しているので音声ファイルは不要です。セーブは端末の localStorage に保存されます。
AI機能（Claude / Gemini）を使うゲームは、各ゲームの設定画面でAPIキーを入力したときだけ有効になります。
